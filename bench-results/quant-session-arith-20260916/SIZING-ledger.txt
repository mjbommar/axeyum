classification is STATIC over the benchmark TEXT, not over the dynamic ground set:
  arith      = a Boolean-position arithmetic comparison (<, <=, >, >=, divisible, is_int)
               occurs anywhere in an assertion.  THE CEILING FOR THIS LANE.
  arithG     = ...and at least one of them is in a GROUND (unquantified) position, so the
               session is refused on round 0 rather than only after an instance lands.
  arithQonly = the comparisons are all under a quantifier: the ground set acquires one
               only through an admitted instance, which is exactly the atom this lane's
               `add_atom_at_root` hook has to accept AFTER construction.
  dt-only    = no arithmetic comparison, but a datatype tester `(_ is C)`.  NOT this lane.
  fun-only   = no comparison at all, but arithmetic FUNCTION symbols (+ - * div mod ...).
               The EUF encoder accepts these -- an `=` over them has an arm -- so the session
               is not refused, but it treats `+` as UNINTERPRETED and can call `sat` where
               LIA refutes.  A SECOND population hosting arithmetic reaches, reported apart
               from the ceiling because the ground check is not what refuses them.
  distinct-only / euf-only = refused for neither reason; hosting LIA changes nothing.
