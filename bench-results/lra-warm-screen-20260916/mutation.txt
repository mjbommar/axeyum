READING THIS
============

Two guards, two suites, because they live in different files and are seen by
different fixtures. Both baselines are NONZERO (3 tests and 16), so neither
result is the "suite compiled to nothing" reading exiting 0.

1. THE THRESHOLD KILLS TWO, AND THAT WAS REGISTERED BEFORE IT RAN
   ---------------------------------------------------------------
   Admitting at 0 builds makes `screened` identical to `on` -- same verdicts,
   same counters, same clock -- so no verdict comparison can see it. Two
   fixtures can, and both die:

     * `a_file_below_the_threshold_keeps_no_basis_at_all` -- the direct guard.
       At a threshold of 0 the screen opens on a 34-build file, so
       `warm_checks == 0` fails and so does the `("off", "below-screen")` label
       pair.
     * `a_file_that_crosses_the_threshold_mid_run_decides_what_off_decides` --
       the signature. At 0 the screened arm answers exactly as many cubes as
       `on`, so `on.warm_checks > screened.warm_checks` fails.

   The brief for this lane asked for EXACTLY ONE named fixture to die. It is
   two; the registration said so before the run; and the honest reading is that
   they observe ONE defect from two sides with NESTED kill sets rather than
   disjoint ones. Manufacturing a single kill would have meant weakening the
   signature assertion -- the one that distinguishes this lane's arm from
   ADR-2125's -- which is not a trade worth making for a tidier number.

2. THE COUNTER KILLS EXACTLY ONE
   ------------------------------
   Moving the always-on bump inside the `--trace` branch is invisible to every
   verdict and to every traced measurement; it shows up only on an
   uninstrumented run, which is every shipped run. Exactly one test sees it --
   `a_screen_count_and_the_traced_count_are_the_same_number` -- and it sees it
   because it asserts the UNARMED half FIRST and separately. A test that only
   compared the two counters while armed would have survived this mutation, and
   an earlier draft of that test did exactly that.

WHAT MUTATION TESTING DOES NOT SHOW
-----------------------------------
The guards that are MISSING. It measures the ones that exist. The adversarial
question -- for every distinction the PRODUCER makes, is there a fixture over a
satisfiable query that can see it -- is answered separately by ADR-2125's
soundness-negative pair, which this lane left untouched and green.
