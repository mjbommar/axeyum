ADR-2132: THE FIVE EXPOSURE DIVISIONS
======================================

Criterion 4 of section 7.1: no stable loss in a division the screen was not
aimed at, each with its own denominator, and a division with no rows reported as
DID NOT RUN rather than as zero movement.

Two arms here -- `off` and `screened` -- and not three. The ship question is
settled on the two `QF_LRA` draws; these ask only whether the screen regressed
somewhere it was not pointed. The `on` arm's columns are written EMPTY rather
than as zeros and the summarizer prints `DID NOT RUN` for it, because an arm
that never started is a different fact from an arm that answered nothing.

`axeyum.v1` (sha256 91675258916e4aeb), 24 s / 8 GiB, s5 pairs `5,13` and
`6,14`, order alternating per file, 100 rows per shard per division.

    division   rows  off  screened  net  gain  LOSS  FLIP  rc!=0  cmp  DIS
    QF_LIA      200  127       127   +0     0     0     0      0  248    0
    QF_UFLRA    200  149       149   +0     0     0     0      0  298    0
    QF_UFLIA    200  162       162   +0     0     0     0      0  324    0
    QF_IDL      200  109       110   +1     1     0     0      0  219    0
    QF_RDL      200  149       149   +0     0     0     0      0  298    0

QF_LIA: ZERO MOVEMENT, AND THE ARM IS INERT -- BOTH, NOT ONE
-------------------------------------------------------------

    screened: rows `built` 0   cubes answered 0   cold tableaux left 0
    off:      cold tableaux 0

Not one file in the division reaches the offline linear loop's cold simplex, so
the screen never had anything to open on and the lever cannot act there at all.

**Reporting the net alone would be the ADR-2111 trap**, which this repository has
been caught by twice: `net +0` from an inert arm is indistinguishable from
`net +0` from a working one that does not help, and only the mechanism counters
tell them apart. So the reading is stated in the form the evidence supports:

    QF_LIA is evidence of NO REGRESSION. It is not evidence of no effect,
    because there was no effect available to measure.

That is the useful answer for criterion 4 -- the criterion asks whether the
screen broke a division it was not aimed at, and a lever that never engages
cannot have. It is NOT an answer to "does the warm basis help QF_LIA", which
this population cannot address.

The cost column agrees: +0.2 % over the 127 rows both arms decide, against a
noise floor measured at 2.4 % on files at or above 50 ms and 0.4 % above 500 ms
(section 6.5). +0.2 % is not a number, it is the floor.

QF_UFLRA: ZERO MOVEMENT WITH THE LEVER ACTIVE -- WHICH IS THE STRONGER RESULT
------------------------------------------------------------------------------

    screened: rows `built` 6   cubes answered 417   cold tableaux left 3,068
    off:      cold tableaux 3,436

Unlike `QF_LIA`, the screen DOES open here: six files cross 64 builds and 417
cubes are answered on a warm basis. So the 0 gains / 0 losses / 0 flips is a
measurement of the lever acting and not regressing, rather than a measurement of
the lever being absent.

That distinction is the whole reason the mechanism columns are printed beside
the verdict columns. `QF_LIA` and `QF_UFLRA` have identical verdict rows and
they do not mean the same thing.

Cost -0.6 % over the 149 rows both arms decide -- inside the noise floor.

A REPORTING DEFECT IN THE SUMMARISER, FOUND ON THIS DIVISION
-------------------------------------------------------------

The mechanism block used to end with a line comparing the screened arm's
`built` count against the `on` arm's, and in a two-arm run it printed

    the screen REFUSED 0 of the rows `on` kept a basis on, and opened on 6 that
    `on` did not (the second should be 0)

`on` did not run. There was nothing to compare, and the line read as a defect
indication -- "the second should be 0" -- about a number that was an artefact of
the absent arm. It now says the comparison is unavailable and why.

This is the same misdiagnosis class as the fuzz runner calling a FAILING suite
an inert one, and the gate runner blaming a lint failure on z3-sys. Three in one
lane, all in tooling this lane wrote, all found by reading the output against
what it was describing rather than by a test.


QF_UFLIA: INERT, LIKE QF_LIA
-----------------------------

    screened: rows `built` 0   cubes answered 0   cold tableaux left 0
    off:      cold tableaux 0

Same reading as QF_LIA and it is stated the same way: evidence of NO REGRESSION,
not evidence of no effect, because no file in the division reaches the offline
linear loop's cold simplex and the lever therefore cannot act. Cost -0.1 %,
inside the noise floor.

So of the three divisions measured so far, ONE (`QF_UFLRA`) has the lever active
and two do not. A reader adding up "three divisions, 0 gains, 0 losses" would be
counting two populations where nothing was exercised alongside one where
something was, and the mechanism columns are what stops that.


QF_IDL: A RAW GAIN ON AN ARM THAT IS PROVABLY INERT
-----------------------------------------------------

    screened: rows `built` 0   cubes answered 0   cold tableaux left 0
    off:      cold tableaux 0

    raw GAIN (off->screened)  QF_IDL/asp/Solitaire/solitaire-edge-time=29.smt2

The lever is INERT on this division -- not one file reaches the offline linear
loop's cold simplex -- and the screened arm still picked up a raw gain.

**That is not a result, and the mechanism columns are what say so rather than a
3x recheck.** The screened arm answered zero cubes on a warm basis anywhere in
the division, so it cannot have caused a verdict to move: below the threshold it
runs the `off` route with one thread-local read per round added. A raw mover
here is ambient by construction.

It is a useful calibration, though. **1 raw mover in 200 rows is 0.5 %**, which
sits inside the 1-1.5 % ambient flip rate these boxes are documented to carry at
a 24 s budget, and it is measured on an arm where the treatment provably did
nothing. That is about as clean an estimate of the floor as this harness can
produce.

The row still goes to the 3x recheck, because "the mechanism says it cannot be
real" is an argument and the recheck is a measurement -- and this lane has spent
the whole day preferring the second.

Cost -0.3 %, inside the noise floor.


QF_RDL: ZERO MOVEMENT WITH THE LEVER ACTIVE
--------------------------------------------

    screened: rows `built` 8   cubes answered 240   cold tableaux left 820
    off:      cold tableaux 1,052

Like `QF_UFLRA` and unlike the other three: the screen opens on eight files and

ALL FIVE, AND WHAT THE COLUMN THAT MATTERS SAYS
================================================

    division   rows  off  screened  net  gain  LOSS  FLIP  cmp  DIS   the lever
    QF_LIA      200  127       127   +0     0     0     0  248    0   INERT
    QF_UFLRA    200  149       149   +0     0     0     0  298    0   ACTIVE  (6 rows,   417 cubes)
    QF_UFLIA    200  162       162   +0     0     0     0  324    0   INERT
    QF_IDL      200  109       110   +1     1     0     0  219    0   INERT
    QF_RDL      200  149       149   +0     0     0     0  298    0   ACTIVE  (8 rows,   240 cubes)
    ---------------------------------------------------------------------------
    total      1000  696       697   +1     1     0     0  1387   0

**0 stable losses, 0 flips and 0 soundness disagreements across 1,000 rows at a
comparable denominator of 1,387.** `cold_restarts` is 0 in every division.

And the last column is why the total is not the headline. **THREE OF THE FIVE
DIVISIONS ARE INERT** -- no file in them reaches the offline linear loop's cold
simplex, so the screen never had anything to open on and could not have
regressed them. Only `QF_UFLRA` and `QF_RDL` exercise the lever, at 14 rows and
657 cubes between them.

So the honest form of criterion 4's answer is two sentences and not one:

    On the two divisions where the lever ACTS, it moved nothing: 0 gains,
    0 losses, 0 flips over 400 rows.

    On the three where it does not act, nothing could have moved, and their
    zeros are evidence about the POPULATION rather than about the screen.

Writing "five divisions, 1,000 rows, 0 losses" would be true and would credit
the screen with three populations it never touched. That is the ADR-2111 inert-
arm trap at division scale, and the mechanism columns are the only thing in this
table that prevents it.

The one raw gain (`QF_IDL`, an inert division) is ambient by construction and
goes to the 3x recheck with any other exposure mover.


THE ONE EXPOSURE MOVER, RE-CHECKED 3x PER ARM
==============================================

The derivation over all 1,000 exposure rows and both comparisons found exactly
ONE mover, and the recheck settles it:

    file                                       A1..A3 (off)              B1..B3 (screened)         verdict
    QF_IDL/asp/Solitaire/solitaire-edge-time=29  unknown unknown unknown   unknown unknown unknown  NEITHER-DECIDES

**It does not reproduce at all** -- 0 of 3 in both arms, where the A/B saw it
decided once under `screened`. Exactly what the mechanism argument predicted: the
screened arm answered zero cubes warm anywhere in `QF_IDL`, so it could not have
moved that verdict, and the raw gain was the ambient flip rate showing up once in
200 rows.

The mechanism said it and the recheck measured it. Both are kept, because the
argument would have been worth nothing if the recheck had disagreed -- and a
lane that only publishes the arguments that were later confirmed is not doing
either.

    divisions, 1,000 rows, 0 soundness disagreements at a comparable denominator
    of 1,387.
