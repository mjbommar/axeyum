# Instances whose rendered Lean module transcribes the query's own TERMS.
#
# Weaker than the `bound` manifest and sharper than the `attested` one. A Farkas
# hypothesis IS one of the query's constraints, so it binds to an `(assert …)`
# line. An array/EUF hypothesis is the CONCLUSION of a congruence derivation --
# for 89 of the 105 queries `ArrayAxiom` certifies, no assertion says
# `¬(lhs = rhs)` at all -- so binding it to an assert line is not a hard check,
# it is a check with no true instance. What holds instead, and is required here:
#
#     every term the module equates is a SUBTERM of the `.smt2` file, under one
#     injective correspondence between the module's opaque names and the file's
#     own symbols, literals and operators.
#
# Swap two arguments, drop a `store`, point an atom at the wrong symbol, or reuse
# one Lean name for two query symbols, and no correspondence exists.
#
# These 95 were 95 of the 124 `attested` before 2026-08-18. The modules changed,
# not the classification: `ProofFragment::ArrayAxiom` rendered ONE opaque
# constant per whole term, so `select(store(a,i,v),j)` and every other term
# reached Lean as `atom._0`. Nothing about the certificate required that -- its
# `lhs`/`rhs` are the query's own `TermId`s, and their combined rendered tree is
# 10 nodes at the median and 156 at the maximum over the whole corpus. It was how
# the emitter was written. `QfAbv` and `QfUf` were ALREADY structural and were
# misfiled as content-free by a check that read vocabulary rather than shape.
#
# Measured 2026-08-18: 95 instances, 2982 matched term nodes.
#
# 2026-08-18, LATER THE SAME DAY: this list is 32, not 95. The other 63 moved to
# `hypothesis-binding-structural-anchored-instances.txt`, which is not a demotion
# -- they earned a SECOND verdict. Their query asserts the disequality outright,
# so anchoring holds of them as well, and recording only the structural half was
# recording the weaker of two true statements.
#
# WHAT IS LEFT HERE IS THE CASE THIS VERDICT WAS CREATED FOR, and now it is the
# only case in it: 32 instances whose hypothesis is a CONGRUENCE CONCLUSION, so
# no assertion of the file says `¬(lhs = rhs)` and nothing anchors. 26
# `ArrayAxiom`, 5 `QfAbv`, 1 `QfUf`. That the class is no longer a mixture is
# what makes its own floor mean something: a drop here is a renderer that stopped
# transcribing, not an instance that drifted between two verdicts.
#
# The pin is now two-sided. A row here must bind structurally AND must NOT
# anchor; if a query starts forcing the disequality its module assumes, this
# gate fails rather than going on recording the weaker statement.
#
# 2026-08-18, LATER STILL: 36, not 32. The 4 `FiniteArrayExtensionality` rows
# joined from `hypothesis-binding-attestations.txt`. Nothing about the

# a module that had every term of the file in it reached Lean saying nothing.

# conjunction is not a fact about either conjunct.
