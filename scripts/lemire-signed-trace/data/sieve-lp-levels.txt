# The sieve level ledger for the Kaser--Lemire window.
#
# LP(n,K) = min sum_{F irreducible, deg F = n} w(F)
#           subject to  w >= 0 on the monic polynomials of degree n
#                       sum_{F : d | F} w(F) = 2^(n - deg d)  for every monic d, deg d <= K.
# By LP duality LP(n,K) is exactly the best lower bound on the number of
# irreducibles in a window W_n that any nonnegative combination of the Type-I
# counts at level 2^K can prove; multiply by 2^(h-n), h = floor(n/2)+1, to put
# it in the W_n normalisation (ambient mass 2^n vs |W_n| = 2^h).
# k_max(n) = min{K : LP(n,K) > 0}.  The window's EXACT (zero-remainder) level is
# K = h, so the barrier is the statement k_max(n) > h.
#
# Producer: scipy/HiGHS (venv), constraints built exactly; the LP=0 rows are
# re-certified over Q by the exact rational populations in
# sieve-parity-population-n*.txt.
# Columns: n | h | K | LP(n,K) | I_n (true count of degree-n irreducibles)
