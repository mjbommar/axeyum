# Public Euclidean recursion decline

Date: 2026-08-21

## Result

The synchronized public recursion proof compiles and has the exact Lean
expression representation of official `Nat.div_add_mod`. Its first independent
Axeyum kernel import nevertheless has footprint `[propext]` and exactly one
direct theorem dependency:

```text
Axeyum.Autogenesis.divAddModPublicRecursion._unary
```

That declaration is generated by Lean for the authored well-founded recursive
theorem. The preregistered gate required the first footprint to be empty before
a second import, so the second submission did not run.

## What this establishes

The earlier opacity blocker is gone: rewriting `Nat.div_eq` and `Nat.mod_eq`
together is sufficient to express and compile the public theorem without the
official proof or the private `div.go` invariant. The remaining blocker is now
the proof representation chosen for recursion, not the public quotient or
remainder interface.

This is not an accepted public support theorem. There was one kernel
submission, no retry, no downstream balanced-Bézout or cancellation work, no
Fibonacci target submission, and no evaluation or ledger credit.

## Next

Preregister a version in which the induction principle is explicit in the
authored proof term rather than emitted as the theorem's generated recursive
equation. The first candidate should use a proof-free, kernel-audited strong
induction interface and preserve the same public equations, statement budget,
exact target type, and fail-closed two-run gate.
