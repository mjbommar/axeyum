Date: 2026-08-21

declaration identity, empty footprint, and empty direct dependency set. The
generic fact-operation boundary additionally requires the canonical kernel
type identity. That hash was not emitted by the original non-rendering batch
audit.

one hash-only audit. The tool may emit only the theorem name, canonical type
and declaration hashes, dependency names, and footprint names. It may not
