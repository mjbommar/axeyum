# All-Nat additive divisibility cancellation adapter

The native foundation already has a clean positive-divisor cancellation
theorem. This adapter handles the missing `d = 0` case by exposing both
divisibility witnesses and deriving `b = 0`; the successor case supplies
primitive positivity to an explicit theorem parameter.

Two fresh imports must agree and have an empty footprint. The positive theorem
remains a parameter, so this increment grants no closed cancellation credit.
