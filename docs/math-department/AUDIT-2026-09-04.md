# Audit of the twelve persona reviews' absence claims

Lane `persona-absence-audit`, 2026-09-04, against `main` at `182d0dd7d`.

**Every claim of absence in `docs/math-department/`'s twelve persona files was
re-checked against the kernel. 76 claims checked. 11 are false — the thing is
proved. 12 more are partially present. 51 are confirmed absent. 2 could not be
settled by search.**

This file is evidence only. It does **not** edit the twelve persona files or
`00-roadmap.md`; the coordinator owns those and applies the findings.

## Why the audit exists, and what it found underneath

Two absence claims in these files were already known false before it started:
`08` first reported the probability shelf as "one theorem" against a real count
near thirty, and `02` lists the fundamental theorem of calculus as its
number-one missing item **a week after both directions were admitted**. Both
failures point the same way and have the same cause.

The cause, re-measured here independently of lane `ftc`:

| measurement | value |
|---|---|
| fact-ledger facts | 2,764 |
| titles beginning `[generated]` — mechanically produced, deliberately no mathematical characterisation | **1,055 (38.2%)** |
| `CReal` facts so titled | **307 of 478 (64.2%)** |
| `CPoint` / `Complex` / `Str` facts so titled | 66.0% / 64.8% / 100% |
| kernel declarations (fresh `--release` build) | **3,575** |
| kernel **theorems** with no ledger fact at all | **430** |
| kernel **definitions** with no ledger fact at all | **762 of 789** |

So a reviewer reading the ledger sees, for 38% of it, a row that says a theorem
exists and refuses to say what it is; and for another 430 theorems and 762
definitions — including `AlgS.Hom.firstIso`, the headline result of `04` —
sees nothing at all. The ledger can answer *is X proved?* and cannot answer
*what do we have?*, which is the only question a review is built from. The
proposal is
[ADR-1605](../research/09-decisions/adr-1605-the-ledger-cannot-tell-uncharacterised-from-absent.md).

**The date cluster is the tell.** Of the eleven false absences, seven landed on
**2026-08-27** — uniform convergence as a carrier, the Weierstrass M-test, the
power-series layer, Fermat/Rolle/MVT, and both halves of the FTC, all in one
day. The reviews were written 2026-09-04. Nothing about that week is hidden;
it is uncharacterised.

## Method, and its controls

- **`shape_search` was rebuilt** through `scripts/cargo-serialized.sh build
  --release` before use (a stale binary reports a false ABSENT, which is how
  this problem started). The fresh binary reports
  `declarations=3575`, `axiom=30 definition=789 theorem=2575 inductive=51`.
- **Positive control landed the same day as the audit:**
  `shape_search --include-constructed --name-contains firstIso --min 1` returns
  `MATCH AlgS.Hom.firstIso theorem arity=5`, exit 0. So the index is current,
  not merely non-empty.
- **Search by step, not by name.** The full declaration index was dumped once
  (`--name-contains '' --limit 99999`, 3,575 rows carrying name, kind, arity
  and the hypothesis/conclusion head shape) and searched offline, so every
  query below is against the kernel environment rather than against source
  text. Ledger `formal.statement` bodies were indexed separately for the
  constants they mention.
- **Coverage confirmed, not just execution.** For the carrier-shaped absences
  (topology, metric spaces, measure, graphs, categories) the check is the
  complete list of all **51 inductive types**, not a keyword miss: no
  topological space, metric space, graph, sigma-algebra, or category is among
  them. An empty keyword result alone would not have been evidence.
- **Definitions vs theorems.** `prelude_theorem_inventory` lists theorems and
  not definitions, so it was not used for existence questions;
  `shape_search --kind` covers both and the index above carries the kind.
- **Two name traps found and avoided.** `Rat.markov_*` is Markov's
  *inequality*, not Markov's *principle* — a name search for "markov" in a
  logic context returns probability. `Rat.bernoulli` is Bernoulli's
  *inequality*, not the Bernoulli *distribution*; the distribution work is
  under `Rat.bernoulli_law_of_large_numbers` and `Rat.indicator`.

## E. How to re-run this audit

```sh
# 1. Rebuild first. A stale binary reports a false ABSENT.
scripts/cargo-serialized.sh build --release -p axeyum-lean-kernel \
  --example shape_search

# 2. Positive control on something that landed TODAY, not merely something
#    that exists. A control that predates the question proves the index is
#    non-empty, not that it is current.
./target/release/examples/shape_search --include-constructed \
  --name-contains firstIso --min 1        # expect: MATCH AlgS.Hom.firstIso, exit 0

# 3. Dump the index once and search it offline, rather than paying the ~70 s
#    environment build per query.
./target/release/examples/shape_search --include-constructed \
  --name-contains '' --limit 99999 > "$AXEYUM_AGENT.decls.txt"
grep -cE 'MATCH +[A-Za-z0-9_.]+ +inductive' "$AXEYUM_AGENT.decls.txt"   # 51 carriers

# 4. The generated-prose share, which is the root cause.
python3 scripts/check-fact-characterisation.py --report
```
