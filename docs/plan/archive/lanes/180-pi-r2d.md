**Diagnosis, offered with its confidence level stated.** The reverted
attempt's numeric leaf, hand-traced, never touches a `Nat` value bigger than
`den(q1)*den(q2) = 25*1875 = 46,875` if combined in the CReal-forced order —
UNDER the doc's own "60,000 = feasible, needs `on_a_deep_stack`" line. That
the un-collapsed nested-tower version still ran to 616s/5.9GB-and-climbing
while my hand-traced worst-case operand size stays under the documented
feasible threshold suggests the cost was not (or not only) final operand
magnitude, but the NESTING DEPTH of un-reduced `Rat.normalize`/`Rat.mul`
towers feeding each other — `Rat.normalize`'s own definition
(`int_prelude/rat.rs`) references its `num`/`den` arguments upwards of ten
times across the positivity/reducedness/value-construction proof terms, so
stacking several un-reduced layers plausibly compounds rather than adds.
**This is a hypothesis, not a confirmed measurement** — I did not build an
isolated A/B (same final operand size, towers vs. flat) to separate "nesting
depth" from "operand size" as the cause, and I have not seen the
collapsed-flat version's own build time to know if the fix actually works.
The `collapse_to_flat` construction mitigates both possible causes at once
(it bounds both the nesting depth AND keeps the final touched magnitude
≤46,875), so it should work under either attribution — but that is an
argument, not a result.

**The literal "rescale every term to a Rat value with denominator 1875"
reading of the brief is impossible in this kernel and was abandoned.** `Rat`
carries an intrinsic `reduced` field (`gcd(|num|,den)=1`); `1875/1875`
(gcd=1875) and `-2400/1875` (gcd=75) are not reduced, so no `Rat.mk` proof
term exists for them — the type itself refuses an un-reduced representative.
What's implemented instead: each term collapses to its OWN naturally-reduced
flat value (`1/1`, `-32/25`, `512/1875`), not a shared-denominator one; the
"combine over 1875" arithmetic happens implicitly inside `Rat.add`'s own
cross-multiplication on those flat values, at a bounded ~46,875 scale rather
than the literal per-term rescale the brief's prose suggested.
