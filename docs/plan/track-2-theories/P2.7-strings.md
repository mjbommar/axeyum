# P2.7 — Strings: unbounded, length-aware, full `str.*` + regex

Status: implementation in progress; bounded and selected source-level routes
landed; the general unbounded target remains incomplete

This file is the P2.7 program index, not the execution queue. Root
[`PLAN.md`](../../../PLAN.md) owns current project priority. The detail set in
[`P2.7-strings/`](P2.7-strings/) contains the current-state snapshot, literature,
target architecture, and phase designs.

## Current implementation versus target

The current implementation is a portfolio:

- first-class `Sort::Seq` IR terms and values;
- a packed-BV SMT-LIB fast path whose declared-symbol window starts at 12 bytes,
  retries at 24/32/48 bytes, and has a 512-byte packed cap;
- a word-level `axeyum-strings` core with normalization, inference, arrangement
  search, replayed SAT assignments, and selected independently checked UNSAT;
- online Boolean-word, regex-membership, lexicographic, and length/LIA routes;
  and
- exact or bounded handling for a broad set of `str.*`/`seq.*` front doors.

That is materially beyond the original ≤16-byte-only design, but it is still
sound-incomplete. The target remains a unified, unbounded, length-aware string
theory with broader regex, extended-function, model-construction, and proof
coverage. Unsupported shapes and exhausted budgets return `unknown`.

Read [the maintained current-state snapshot](P2.7-strings/00-current-state.md)
before using the phase documents below. The phase documents retain design
history and target contracts; they are not evidence that every described slice
has landed.

## Scoping fact

Quantifier-free word equations combined with general length arithmetic have an
open decidability boundary, and adding string/integer conversion makes broader
fragments undecidable. P2.7 therefore targets useful admitted fragments and
must remain fail-closed outside them. The project contract is not “complete on
all strings”; it is “return only replayed or checked results, otherwise
`unknown`.” See the [literature review](P2.7-strings/01-literature.md) for the
cited results.

## Standing discipline

- Preserve first-class `unknown` outside admitted fragments or resource bounds.
- Replay every returned SAT model against the applicable untouched source
  obligations.
- Require a route-specific checker or an explicit trust-ledger boundary for
  UNSAT; one checked subroute does not certify the whole fragment.
- Keep the default product path pure Rust and deterministic.
- Bind performance/parity claims to retained artifacts rather than copying
  historical counts into this index.
