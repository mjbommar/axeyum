## What

Wrap the existing `dispatch_*` arms (`dispatch_int_linear_refuters` 2033, `dispatch_uf_fast_paths`
2261, `dispatch_abv_online` 3168, `dispatch_array_unsat_refuters` 3326,
`dispatch_int_blast_width_ladder` 5054, ...) as table-driven chain entries with per-edge budgets and a
composed `ModelReconstructionTrail`. **Slice one arm family per PR.**

## Files touched

- `crates/axeyum-solver/src/auto.rs`
- `crates/axeyum-solver/src/bridge.rs`

## Exit criteria

- Each slice passes the full solver `--lib` sweep, `corpus_regression`, and `progress_frontier`

## Notes and traps

**This is the riskiest engineering in the track.** 8,616 lines of interleaved fast paths with
order-dependent semantics; the 829-commit `nia_unsat` bisect shows silent frontier regressions ship.

The existing arms *are* the chain executors -- this is repackaging, not rewriting. Resist the urge to
"clean up" semantics while moving code.

Model-lift composition across multi-hop chains is a correctness surface as sharp as any solver kernel;
add soundness-negative tests per composed pair.
