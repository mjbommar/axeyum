## What

Enumerate the chain space offline: ordered products over edges up to depth 5, filtered by
`signature_composable` and `reaches_decider`, with `trust_cost` = count of uncertified edges and a
stable id.

## Files touched

- new `crates/axeyum-solver/src/bridge.rs` additions
- test + golden chain listing

## Exit criteria

- Enumeration deterministic, count stable, golden-tested like `trust_ledger_markdown`

## Notes and traps

Canonical order = `ALL_TRUST_IDS` source order (`trust.rs:124-139`); that is the determinism anchor.

Bidirectional / meet-in-the-middle search collapses into `reaches_decider`: the backward frontier is
precomputed once, offline, exactly. There is no runtime bidirectional search to write.
