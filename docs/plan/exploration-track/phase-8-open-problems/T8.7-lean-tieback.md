| | |

## What

Generate `example : not (P k) := by decide` (or `native_decide`) for every witness found, compiling
against the pinned tag.

## Files touched

- the Lean project plus a CI job (non-default, network-fetching, like the official-Lean gate)

## Exit criteria

- Every `witness-found` pack has a compiling Lean file
- **Policy: no witness claim published without it**

## Notes and traps

**This is what makes the claim about the formal conjecture rather than about axeyum's transcription of
it.** Without the tie-back, a witness only says something about the encoding.

Long term, route the exported statement through `axeyum-lean-import` for an in-house check --
connecting this phase to phase 9's R6 rung.
