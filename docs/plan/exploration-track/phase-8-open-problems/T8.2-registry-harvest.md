## What

Harvest all 509 Erdos files from `google-deepmind/formal-conjectures` into registry rows pinned to an
immutable `bench-v{N}` tag: category, AMS, answer polarity, reference URL, decl name.

## Files touched

- `scripts/harvest-formal-conjectures.py`
- `docs/open-problems/registry/`

## Exit criteria

- 509 rows pinned to a tag; **>= 98% of main statements resolved** (a throwaway regex reached 501/509)
- The open/solved split reproduced (expect ~316 open / 164 solved)

## Notes and traps

The repo is *designed* for machine consumption -- linter-enforced metadata and a 564-line `AGENTS.md`.
Use it rather than scraping erdosproblems.com, which returns 403.
