## What

Extend the bench per-instance JSON with route id, trust class, outcome class, censored cost, and
feature cost; add an exporter producing an ASlib-style scenario (feature table + runtime table +
splits stub).

## Files touched

- `crates/axeyum-bench/src/main.rs`
- new export script under `scripts/`

## Exit criteria

- One `just` recipe produces an ASlib-style scenario from a bench run

## Notes and traps

ASlib requires the *cost of feature computation* as a first-class column -- do not omit it, or later
comparisons will silently flatter the policy.
