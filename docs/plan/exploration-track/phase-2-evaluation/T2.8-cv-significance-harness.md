# T2.8 — Family-grouped CV + significance harness

| | |
|---|---|
| Phase | 2 - evaluation harness |
| Size | M |
| Depends on | T2.2, T2.4 |
| Blocks | T2.9 |

## What

Group k-fold at family level with committed split manifests; Wilcoxon signed-rank on per-family
PAR-2; bootstrap CIs resampled over families; permutation test for headline claims; Holm correction.

## Files touched

- analysis scripts under `scripts/`
- results artifact schema

## Exit criteria

- Reproducible CV report with significance testing
- Split manifests committed

## Notes and traps

Resample over *families*, not instances -- resampling instances treats correlated variants as
independent evidence and produces confidence intervals that are far too narrow.
