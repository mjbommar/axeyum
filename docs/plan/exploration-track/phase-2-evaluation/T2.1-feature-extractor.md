## What

Extract and extend `Features` (`auto.rs:7171`) into a serializable `FeatureVector` computed in one
deadline-aware DAG walk plus one optional capped probe. Tiers 1-3 as described in the phase README.

## Files touched

- new `crates/axeyum-solver/src/features.rs` (extracted from `auto.rs`)
- unit tests per fragment

## Exit criteria

- Features emitted as stable JSON for all 140 `corpus/regression` + 43 `corpus/qfbv-curated` instances
- Snapshot test; identical output across two runs
- No wall-clock dependence

## Notes and traps

Reuse `prove_int_box` (`auto.rs:4133`) for the int-bound-box feature rather than recomputing it.

The capped-lowering probe is the single most predictive cost signal (the `reduction_shrinks_encoding`
data) **and** the most expensive feature. Budget it and record its cost -- the SATzilla discipline.
