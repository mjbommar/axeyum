| | |

| Size | M |

## What

Extract the `progress_frontier` family generators (they currently live inside the test file) into a
reusable module, and extend the `axeyum-scenarios` catalogs to emit (family, N, seed) triples.

## Files touched

- `crates/axeyum-solver/tests/progress_frontier.rs` (extract generators)
- `crates/axeyum-scenarios/`

## Exit criteria

- At least 10 families with graduated `N` and self-checked ground truth, runnable through axeyum-bench

## Notes and traps

This is where the *difficulty gradient* comes from. The packs supply labels; they cannot supply
signal, because every pack instance decides in milliseconds.

Inherit the frontier's discipline: decided-but-wrong is a hard failure, not a low score.
