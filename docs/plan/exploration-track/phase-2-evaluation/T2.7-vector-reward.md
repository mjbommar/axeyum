## What

Implement the lexicographic `(soundness, strength, trust, -cost)` reward, plus the pinned scalar
collapse for bandit updates, with the assurance mode declared per episode.

## Files touched

- bench episode logger
- small reward module

## Exit criteria

- Both the vector and the pinned scalar are emitted per episode
- The wrong-verdict path quarantines the instance into `corpus/regression` and hard-fails

## Notes and traps

`wrong` is not a low reward -- it aborts the run and files a soundness bug. Never let a learner trade
soundness for speed.

A learner will exploit any alpha/beta that lets uncertified-fast dominate certified-slow. Publishing
the vector and gating on the lexicographic ordering bounds the damage.
