## What

A drop-in binary speaking the exact contract Comparator uses for nanoda: parse the JSON config
(honoring `use_stdin`, `permitted_axioms`, `unpermitted_axiom_hard_error`; accept
`nat_extension`/`string_extension` and **fail closed** until implemented), stream stdin through
`import_ndjson` with raised limits, gate `ImportReport::axioms` against the whitelist, and map outcomes
to exit codes.

## Files touched

- new `crates/axeyum-lean-import/src/bin/`
- `crates/axeyum-lean-import/src/lib.rs` (limits parameter, semver-range option)

## Exit criteria

- Config parse + stdin import + axiom gate + exit-code map
- Unit tests including a whitelist violation and the decline path
- Exit codes: 0 accept, 1 kernel rejection, 2 `ImportError::Unsupported`, >=3 malformed/IO

## Notes and traps

Comparator has **no plug-in API** -- `COMPARATOR_NANODA=<path>` is an impersonation seam, not a
contract, and the hardcoded config shape can change without notice (HEAD already moved to
4.33.0-rc1).

Exit code 2 (decline) is what makes Arena entry possible with an incomplete kernel; get the mapping
right first.
