## What

Submit a checker YAML to `leanprover/lean-kernel-arena` (build command, run reads `$IN`, `declines:`
list) and add a local `just` target for the Arena suite.

## Files touched

- an Arena fork PR (external)
- `justfile` target, bench notes

## Exit criteria

- Checker accepted upstream or running locally against the full Arena suite
- Declines are honest; conformance failures triaged

## Notes and traps

**The Arena explicitly welcomes incomplete kernels** -- exit code 2 declines are first-class. Its 135
accept/reject conformance tests become a free soundness-negative suite, and its corpus ladder (init
1.1 min -> std 1.9 min -> cslib/cedar -> mathlib 30 min) is a measured ratchet in the
`progress_frontier` mold.

There is currently **no axeyum and no non-nanoda-lineage Rust kernel** in the Arena.
