| | |

| Size | L |

## What

Implement Lean-verbatim kernel semantics for `Nat.add/sub/mul/div/mod/pow/gcd/beq/ble/land/lor/xor/
shiftLeft/shiftRight` on literals, BigUint-backed.

## Files touched

- `crates/axeyum-lean-kernel/src/tc.rs`, `expr.rs`, tests

## Exit criteria

- Verbatim semantics on literals
- Differential tests against pinned real `lean`
- **Degenerate-case fuzz seeds** (`Nat.div`-by-zero literals, etc.)

## Notes and traps

Currently only succ-folding and literal/constructor conversion exist; `tc.rs:1484` states plainly that
general arithmetic remains TL2.8.

This is soundness surface **in a checker**. Fixture passes are not enough -- per the Hard Rules, every
partial operator needs a fuzz seed-class generating the degenerate argument.
