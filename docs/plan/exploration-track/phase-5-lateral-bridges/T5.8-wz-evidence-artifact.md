## What

Serialize `R(n,k)` plus base cases from `prove_wz_sum` (`lib.rs:6204`), and write a **minimized**
independent checker that performs only rational-function arithmetic.

## Files touched

- `crates/axeyum-cas/src/lib.rs` (WZ region)
- new checker function

## Exit criteria

- The checker validates all shipped `prove_*` families and rejects a perturbed `R`
- Documented as CAS-surface evidence, not solver search widening

## Notes and traps

`certifies_wz_sum` (`:5626`) already implements the check, but it leans on the crate's `equal`, whose
`canonicalize_for_equality` chain (Gamma-recurrence, Gamma-reflection, Euler rewrite, prime-basis
logs, `lib.rs:~2050`) is a large trusted surface. Fine for the CAS's own trust tags; it **erodes
"small trusted checker"** if imported wholesale. Hence the minimized re-implementation.

This is the purest instance of the axeyum architecture in the whole CAS -- one rational-function
identity -- and the best demonstration artifact. It is also, honestly, not search-space widening: the
IR has no factorial or binomial heads for it to fire on.
