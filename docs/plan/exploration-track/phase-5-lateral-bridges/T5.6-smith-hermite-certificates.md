## What

Serialize `(U, V, S)` from `normalforms.rs` (Hermite :450, Smith :479 -- both already return transform
matrices) with a Bareiss unimodularity check, and compose the infeasibility/solution route into
`DiophantineCertificate`.

## Files touched

- `crates/axeyum-cas/src/normalforms.rs` (read-only reuse)
- `crates/axeyum-solver/src/certify.rs`, `lia*.rs`
- ADR-0042 follow-up

## Exit criteria

- `U*A*V = S` and `det U,V = +/-1` re-checked independently
- Lean int-prelude reconstruction path documented
- Degenerate fuzz: zero matrix, rank-deficient input

## Notes and traps

These are already in certificate shape -- this is the lowest-effort class-A lateral bridge in the
phase. Infeasibility reads off the Smith divisors; feasibility is an explicit solution replayed by
evaluation.
