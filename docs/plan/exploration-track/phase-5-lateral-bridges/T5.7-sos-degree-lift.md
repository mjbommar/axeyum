## What

Extend `SosCertificate` beyond degree 2 using an exact-rational LDL^T / diagonally-dominant Gram
search -- no SDP required.

## Exit criteria

- A degree-4 AM-GM-class corpus decides
- `verify` rejects mutated certificates
- Degenerate fuzz seed-class: zero polynomial, rank-deficient Gram

## Notes and traps

`SosCertificate::verify` (`nra_real_root.rs:6335`) already never trusts the producer's matrix -- the
checker side is sound, only the search side is narrow.

Full SDP-backed SOS is a separate arc: floating SDP to exact rational rounding fails precisely on
non-strictly-feasible instances (Monniaux-Corbineau), and there is no pure-Rust SDP. Do not start
there.
