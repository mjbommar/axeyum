## What

Add `crates/axeyum-solver/src/bridge.rs` with the sealed `Bridge` trait, `AppliedBridge` (target,
per-query direction, owed trust steps, model lift), `Chain` (private `composed`, monotone `extend`,
`conclude` as the only source-verdict constructor), and `LicensedVerdict` with a private field.

Pilot edges: `lazy_bv`, the int width ladder, and bounded int-blast -- chosen because they span
over-approximation, under-approximation, and guarded equivalence.

## Files touched

- new `crates/axeyum-solver/src/bridge.rs`
- adapters for `lazy_bv.rs`, the int width ladder, bounded int-blast

## Exit criteria

- Pilots decide only via `Chain::conclude`
- A route_trace-style differential test proves behavior identical to the existing direct calls
- `Bridge` sealed; `LicensedVerdict` unconstructible outside the module

## Notes and traps

Replay lives **inside `conclude` and is bound to `self.source`**. That single placement closes the
replay-against-an-intermediate trap by construction -- but only if no other sat-emitting path exists.
Auditing for bypasses is part of T1.6's exit criteria, not an afterthought.

An edge whose guard check *errors* must not be caught and treated as "guard passed weakly":
error != decline != weaker direction.
