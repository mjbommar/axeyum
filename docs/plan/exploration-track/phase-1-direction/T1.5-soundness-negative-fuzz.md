## What

Build the seed families that *construct the divergence* for every direction-bearing edge, and assert
the system emits `Unknown` rather than the unlicensed verdict. Families: ladder-poison,
abstraction-poison, relaxation-poison, guard-epsilon, and a random-chain differential.

## Files touched

- new `crates/axeyum-solver/tests/direction_negative.rs`
- fuzz generators

## Exit criteria

- All five seed families present
- **Every single-edge direction flip (OVER/UNDER/EQ) is caught by at least one seed** -- the teeth
  requirement
- Wired into the pre-merge gates (`--lib` sweep, `corpus_regression`); `progress_frontier` untouched

## Notes and traps

This is the CLAUDE.md degenerate-argument rule transposed to composed bridges. A gate that only sees
honest chains is blind exactly where the `a946f925` div-by-constant-zero incident says fuzzes go
blind.

Concrete shapes: `x = 2^80` (SAT only above every ladder width); `x*x = -1` class (UNSAT whose
fresh-var abstraction is SAT); `2x = 1` (int-UNSAT / real-SAT); box bound off by exactly `2^w`;
FP width 129; op-list plus one rounding op.
