## Notes and traps

`proof_sat.rs` has **no assumption interface** (grep `assum` returns nothing), unlike `IncrementalSat`
(`lib.rs:686-816`). Either add one or use cube-as-units with proofs relative to F and the cube -- decide
before starting.

**SAT cubes are normal**, not an error: PTN cube 343,864 was SAT in an intermediate phase. The SAT path
must replay against the original term and still record which cubes were never conquered.
