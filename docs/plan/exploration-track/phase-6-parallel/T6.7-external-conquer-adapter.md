## What

Subprocess adapter configured by binary path, exactly like `cnf_core_bench.rs`.

## Files touched

- the orchestrator module plus config

## Exit criteria

- Differential agreement plus native proof recheck on the corpus
- **Builds and runs with no external binary present**, degrading to the native engine

## Notes and traps

**Trust laundering is the trap.** An external solver's *verdict* must never propagate -- only its
checked proof or replayed model. A kissat timeout is `unknown`, never `unsat`. Enforce at the type
level: `ProofSource` required to construct an UNSAT verdict.
