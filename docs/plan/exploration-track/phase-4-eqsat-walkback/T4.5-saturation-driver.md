## What

An egg-Runner-shaped loop: rounds of (match batch -> apply -> merged?), deterministic rule order, a
node budget, an iteration budget, and a per-round match-work budget. RHS instantiation via `add` then
`merge` with a fresh ledger reason.

## Files touched

- new `crates/axeyum-solver/src/eqsat.rs` (or `axeyum-rewrite`, per T4.1)

## Exit criteria

- Saturates the starter rule set on micro terms
- Deterministic across runs
- Budget exhaustion leaves clean partial state, never panics

## Notes and traps

Reuse the existing count-based cap idiom (`lib.rs:35-105`) -- clock-free, wasm-safe,
determinism-preserving.

**Grow-only within one scope.** `pop` bumps `rollback_epoch` and clears `merge_events`
(`lib.rs:908-922`), forcing a full `EMatchIndex` rebuild; interleaving eqsat with CDCL(T) push/pop will
thrash. Harvest chains *before* popping the scope that created them.

Eager congruence re-canonicalizes parents on every merge where egg batches it. Do not pre-optimize,
but include a merge-heavy shape in the G2 measurement.
