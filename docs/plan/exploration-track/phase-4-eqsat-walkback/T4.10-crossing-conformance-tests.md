# T4.10 — Evidence-crossing conformance tests

| | |
|---|---|
| Phase | 4 - eqsat and walk-back |
| Size | M |
| Depends on | T4.9 |
| Blocks | none |

## What

For each REDERIVE/LEMMA bridge, a corrupted-certificate rejection test; for each NONE, a
ledger-visibility test.

## Files touched

- solver tests

## Exit criteria

- Every crossing mode has a negative test

## Notes and traps

A NONE bridge that silently reports `certified: true` is the failure this catches. The ledger's
per-run `TrustStep::certified` is the field under test, not the global `is_certified` bit.
