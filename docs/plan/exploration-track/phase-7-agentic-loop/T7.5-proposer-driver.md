curated unknown bucket.

## Exit criteria

- Pilot completes under $100
- Report: conversions, cost per conversion, ledger committed

## Notes and traps

**The measured go/no-go for the whole phase.** If it converts fewer than roughly 5 problems per $100,
demote the runtime loop to T7.9 (decline mining) and T7.10 (shadow generation), which is where
FunSearch-style loops historically paid off anyway.

Graded fitness is not optional: raw sat/unsat/unknown is too flat to drive anything. Build it from
*checked* quantities, never from solver-reported statistics alone (the `f5b00c72` vacuous-sat lesson).

Never sweep the 45,905-path library with an LLM: >= $2-10K even on Haiku, and rule 11 of the agent
program forbids sweeping for progress.
