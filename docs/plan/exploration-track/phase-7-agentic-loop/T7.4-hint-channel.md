## What

Accept externally supplied instantiation terms, bounds, and entailment-checked cut lemmas, all
verified before use.

## Files touched

- `crates/axeyum-solver/src/auto.rs`, `backend.rs` (config), new `hints.rs`
- tests

## Exit criteria

- Differential gate: across all corpus queries, hints **never flip a verdict** -- only
  `unknown -> decided` with evidence
- **Adversarial-hint fuzz: deliberately wrong lemmas produce `VerifierRejected`**

## Notes and traps

This is the only real soundness surface in the phase. `abduct.rs` is the pattern to copy verbatim:
candidate generation entirely untrusted, soundness only from re-checking with the trusted decider.

Per CLAUDE.md's degenerate-case rule, the fuzz generator must emit malformed, ill-sorted, dishonest,
and direction-violating proposals. A loop tested only on honest model output is blind exactly where it
is fragile.
