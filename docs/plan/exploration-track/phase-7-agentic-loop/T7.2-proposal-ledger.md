| | |
|---|---|
| Phase | 7 - agentic loop |
| Size | S |

| Blocks | T7.5, T7.8 |

## What

The JSON proposal schema plus an append-only, content-addressed JSONL ledger recording prompt hash,
model id, request params, seed, raw response, fitness, and evidence hash.

## Files touched

- new `crates/axeyum-agent/src/{proposal,ledger}.rs`, or a module in `axeyum-bench`

## Exit criteria

- serde round-trip; content-hash stability test
- **Replay-from-ledger determinism test with zero network calls**

## Notes and traps

This is the determinism seam. Discovery is nondeterministic and is never a claim; results are
reproducible because replay consumes the ledger. Model deprecation means old proposals cannot be
*regenerated* -- acceptable, because replay never needs the API.
