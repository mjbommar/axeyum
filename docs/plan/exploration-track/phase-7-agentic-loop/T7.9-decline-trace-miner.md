| | |

| Size | M |
| Depends on | T7.3 |

## What

Cluster decline traces and produce a ranked mechanism-gap backlog. Zero soundness surface.

## Files touched

- `scripts/`, a report under `docs/plan/`

## Exit criteria

- Ranked report cross-checked against the Lane A/B/C censuses
- At least one adopted backlog item

## Notes and traps

**Possibly the highest-value role in the phase**, because the measured gap is dominated by
`DeclineReason::Unsupported` -- which no runtime loop converts, but which a good backlog does. One
frontier-model run over the whole trace corpus costs ~$1-3.
