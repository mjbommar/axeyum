## What

A restricted DSL letting the agent emit chains over *declared* bridges, executed by an interpreter
that honors declared soundness directions.

## Files touched

- `crates/axeyum-solver/src/bridge.rs` (phase 1) plus a DSL layer

## Exit criteria

- Agent-emitted chains execute or reject deterministically
- Verdict transfer only along the declared direction

## Notes and traps

Hard-depends on phase 1's `Direction`/`LicensedVerdict` types. Without them there is no way to make a
dishonest chain merely wasteful rather than unsound -- which is the entire architectural requirement.
