## What

Emit `artifacts/ontology/bridge-catalogue.json` from `bridge_catalogue_json()`, with a schema file
and a dependency-free Python validator mirroring `scripts/validate-smt-fragment-atlas.py`.

## Files touched

- `artifacts/ontology/bridge-catalogue.json`, `bridge-catalogue.schema.json`
- `scripts/validate-bridge-catalogue.py`
- `crates/axeyum-solver/tests/bridge_catalogue.rs`
- `justfile` (`foundational-resources`), `docs/atlas/` note

## Exit criteria

- `just foundational-resources` validates the catalogue
- The golden test pins JSON to the registry byte-for-byte
- Atlas cross-references resolve; `trust_ids` are a subset of the 14 ledger labels
- Soundness-consistency rules enforced (`verdicts: unsat` implies `sat_transfer: none`;
  `sat_transfer: replay-checked` implies `walk_back != none`)

## Notes and traps

`source_fragments` may legitimately be empty -- dispatch guards are finer than the 10 atlas rows.
Never force an edge into a row; that either spawns junk rows or produces lossy labels.
