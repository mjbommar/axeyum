## What

`RouteTrace` has no serde and is never persisted, so there are no logs to validate a catalogue
against. Add a deterministic JSON rendering and persist a per-file trace in the bench artifact.
This is the prerequisite that makes T0.4 possible at all.

## Files touched

- `crates/axeyum-solver/src/route_trace.rs` (serde or a manual deterministic render)
- `crates/axeyum-bench/src/main.rs` (per-instance trace in the JSON artifact)
- `crates/axeyum-bench/examples/explain_corpus.rs`

## Exit criteria

- `just bench-micro` artifacts contain route traces
- Rendering is byte-stable across two runs of the same input
- The verdict-invariance differential suite (`tests/route_trace.rs`) stays green

## Outcome (2026-08-01) — `WIP`, 2 of 3 files

**Landed:**

- `crates/axeyum-solver/src/route_trace.rs` — `RouteTrace::to_json()`, a
  hand-rolled deterministic single-line renderer (the crate has no serde, and the
  dependency-free style matches `scripts/validate-smt-fragment-atlas.py`), plus
  `ROUTE_TRACE_JSON_SCHEMA_VERSION` and a public `push_json_string` so consumers
  embedding a trace escape their own fields with the *same tested* routine rather
  than a second one that drifts. Five unit tests: empty trace, every outcome
  variant's documented shape, `UnknownKind` wire names, control/quote/backslash
  escaping, and byte-stability + dispatch-order preservation.
- `crates/axeyum-bench/examples/explain_corpus.rs` — a `--json` mode emitting
  JSONL (`file`, `status`, and conditionally `verdict`/`trace`/`detail`),
  backward compatible with the existing positional call sites.

**Verified end to end**, not just unit-tested: run over `corpus/regression`,
140 lines emitted, **all 140 parse as valid JSON**, 127 carrying a trace.

**Gates run and green:** `--test route_trace` (the verdict-invariance
differential, 12/12), full solver `--lib` sweep under `--features full`
(967/967), `--test corpus_regression`, `--test progress_frontier` (9/9),
`cargo doc` with `RUSTDOCFLAGS=-D warnings`, and clippy — **zero findings in
either changed file**.

**Still open, and now known to be BLOCKED — a dependency error in this plan.**

The exit criterion "`just bench-micro` artifacts contain route traces" cannot be
met as written. `axeyum-bench` calls **`solve()`**, not `check_auto_explained`
(`crates/axeyum-bench/src/main.rs:~2340`, inside the `catch_unwind` isolation),
and `solve()` (`auto.rs:318`) contains **zero recorder call sites** — verified by
grep across its whole span. There is no `solve_explained`; the only traced entry
point is `check_auto_explained`, which covers the quantifier-free region only.

So there are exactly three ways forward, and two are wrong:

1. **Point the bench at `check_auto_explained` instead.** Rejected — it skips
   `solve()`'s quantifier preamble, so the harness would stop measuring what it
   measures today. That is a measurement-integrity break, not a refactor.
2. **Thread a recorder through `solve()` without adding preamble recorder
   sites.** Rejected — it yields traces that silently omit the preamble, which is
   precisely the "silent skip" blindness [T0.4](T0.4-behavioral-replay-validator.md)
   warns about; a trace that looks complete but isn't is worse than none.
3. **Do [T0.6](T0.6-coverage-expansion.md) first**, adding recorder sites to the
   `solve()` preamble and the quantifier engines plus a `solve_explained` entry
   point, then persist from the bench. Correct, and the reason T0.6 is now a
   prerequisite of this task rather than an independent slice.

**Dependency correction:** this task was authored as "Depends on: none". That is
true of the *rendering* half (landed) and false of the *bench* half, which
depends on T0.6. The header dependency and the phase README have been updated.

### Gotcha worth propagating

`cargo test -p axeyum-solver --lib` compiles only **23** tests. The module list —
including `route_trace` — lives inside a `full_modules!()` macro gated on
`#[cfg(feature = "full")]` (`lib.rs:34`, `:195`), so the bare `--lib` build does
not contain them; `--features full` yields **967**. CLAUDE.md already warns that
`--lib` is not a sufficient pre-merge gate because it skips `tests/*.rs`; this is
a sharper form of the same trap, because `--lib` can silently skip *unit* tests
too. Any task in this track that gates on `--lib` must pass `--features full`.

## Notes and traps

Recording must remain a pure side effect. The contract at `route_trace.rs:10-25` is structurally
enforced via the optional `Recorder`; do not introduce a convenient guard-on-recorder shortcut --
that would be a P0.
