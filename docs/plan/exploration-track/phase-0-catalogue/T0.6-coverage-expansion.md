## Promoted from "independent slice" to a prerequisite (2026-08-01)

Discovered while attempting T0.1's bench half: **`axeyum-bench` calls `solve()`,
not `check_auto_explained`**, and `solve()` has zero recorder call sites. There
is no `solve_explained`. So no bench artifact can carry a route trace until this
task lands.

That makes this task's real deliverable two things, not one:

1. Recorder sites across the `solve()` preamble (ground-subset refutation,
   checked fast paths, counterexample normalization, skolemization, the lazy-BV
   CEGAR hook, valid/vacuous-universal elimination) and the quantifier engines
   (`prove_unsat_by_mbqi` :6109, `prove_unsat_by_instantiation` :6462,
   `prove_unsat_by_ematching` :6488).
2. **A public `solve_explained` entry point**, mirroring
   `check_auto_explained`, so consumers get a trace without changing which
   solver path they exercise.

Both must preserve verdict invariance the same structural way `check_auto` does:
the recorder is threaded into the *same* dispatch, never into a branch condition,
and the differential in `tests/route_trace.rs` is extended to cover the
quantified surface.
