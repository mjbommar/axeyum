## What

Audit every edge's `sat_transfer` / `unsat_transfer` / `walk_back` against the code, each with a
`sources` line reference, and land the ADR for the direction vocabulary (queue item B1).

## Files touched

- `crates/axeyum-solver/src/route_registry.rs`
- `docs/research/09-decisions/` (new ADR)
- new cross-check test against `evidence.rs`

## Exit criteria

- ADR merged
- Every edge with non-empty `trust_ids` matches what `evidence.rs` attaches for that route family
- Audit test green

## Notes and traps

`evidence.rs` attaches `TrustStep` sets per certificate route (e.g. 1455-1470, 3242-3259) -- a second,
independent, hand-maintained route-to-trust mapping. The catalogue should subsume or cross-check it,
not add a third.
